Features

它不是「又一个聊天框」，
而是一套会长大的助手运行时

普通 App 的字段是产品经理写死的，白泽的字段是你说出来的。 为了让这件事真的能跑，底下有模型版本、脚本沙箱、权限审批和持久化任务在撑着。

🗣️

一句话创建助手

「帮我管客户资料和跟进记录，别漏跟进。」主助手女娲会读出你的意图， 建好助手、写好指令，并替你规划需要哪些数据结构。你不需要面对 System Prompt、Schema 和工具列表。

🧱

数据结构由对话长出来

每张表、每个字段、每次引用关系都可以在聊天里增删改。 改动前它会先给你一份影响报告（有多少条记录会受影响、要不要迁移），你点头了才动。

🧩

缺什么工具，它自己写

需要算「这个月超支了多少」这类逻辑时，助手会写一段 JavaScript Action： 先跑测试，通过后发布，之后每轮对话都能调用，跑在受限的脚本沙箱里。

📊

聊天里直接长出界面

它可以用声明式组件（A2UI）搭出统计卡、表格、图表和确认卡， 直接在气泡里渲染。界面存在消息里，重开聊天不用重新算一遍。

🗂️

[数据] 开关：聊天的第二平面

顶部一个开关切到数据页：台账、筛选、统计卡，一屏看完。 这一路完全不经过模型——没有 token，也没有等待。

📨

助手之间会转达

业务助手遇到自己管不了的事，可以请主助手帮忙； 主助手也能问它要情况。转达只有单向往返，不会互相踢皮球。

🎙️

能说话，也能被说话打断

系统级语音识别与合成：随手一句就落成一条记录，也可以整段语音对话。 它念到一半你插话，它会停下来听你说。

⏰

到点自己干活

巡检、到期提醒、月度汇总都可以排成持久任务：应用重启不丢， 失败会退避重试，超过上限就老实记成失败留给你看。

📤

数据是你的，能带走

一次导出：每个助手一个工作簿、每张表一个 sheet、关联字段展开成名字、金额是真正的数字。 打成一个 zip 直接系统分享，不要存储权限。

开始使用

四步，从零到一个能用的助手

首次打开会有一个 8 步本地引导，用假数据演示，不碰你的真实记录，也不调用模型。

配一个模型服务

设置 → 模型服务 → 选 DeepSeek / OpenAI / Moonshot / 任意 OpenAI 兼容端点， 填 Base URL、模型名、API Key。Key 存在 Android Keystore 加密存储里。

跟主助手说一句话

「帮我记随份子，谁给的、我该回多少，别搞混。」 它会建助手、写指令，并规划出「人情」「关系」这些表。

切到它，正常聊天

顶部点名字旁的三角切换助手。记账、查询、改结构都用日常话说， 顺手可以按住麦克风说出来。

需要时打开数据页

拧一下 [数据] 开关看台账和统计。想加字段、改口径，回聊天里说， 看过影响报告再确认。

它和别的不太一样的地方

这些东西不能靠「更好的提示词」解决

本地优先

助手的运行、数据、权限判定、备份全在手机上完成，不依赖任何自建后端；除了模型推理那一跳，断网也能查、能改、能导出。

能力是一等公民

每个助手有自己的模型、表和工具。主助手管创建和升级，业务助手只干自己的活，两边的能力集合互斥。

每次改动都可审计

工具调用、参数、结果、耗时、错误、权限判定都写进执行日志；结构改动有版本快照，可以按字段合并着回滚。

幂等与事务

「记一笔午餐 35」在网络超时后不会变成两笔账：副作用操作带幂等键，业务写入和幂等记录在同一个事务里。

一个入口，不迷路

整个 App 只有一个聊天界面，助手用顶栏切换。没有底部导航迷宫，也不用记功能在哪个标签页。

外观随你

每个助手可以换名字、换形象、换配色（6 种），Android 12+ 还能跟随系统动态取色；形象是手绘的豆形，不是机器人。

安全与隐私

权限在运行时里校验，
而不是在提示词里祈祷

一个能自己建表、自己写脚本的助手，最危险的地方不是它会不会乱说话， 而是它能不能绕过你的授权。白泽把授权点放在引擎边界： 能力匹配、资源范围、审批、审计都在实际访问资源的那一下发生。

能力 + 资源范围

「有读权限」不等于「能读所有表」。模型、记录、脚本、设备权限都带范围，跨助手访问默认拒绝。

审批矩阵

加字段、改结构这类有破坏性的操作必须你确认；风险报告会说清影响多少条记录、还能不能撤销。

脚本沙箱

脚本只有白名单 Host API，强制超时、内存上限、栈上限、调用次数与递归深度；只有测试通过的版本才能发布执行。

防提示注入

你记录里的文字是数据，不是指令。工具结果不能修改工具权限，高风险动作一律回到你面前确认。

密钥进 Keystore

模型 API Key 用 Android Keystore 加密存放，不写进日志，也不随导出的数据一起走。

本地备份

备份带清单和版本校验：版本对不上就拒绝恢复；恢复要重启生效，界面会直说，不会假装已经恢复。

也说清楚边界

  • 模型推理不本地。你用哪家模型，那一轮对话（含工具结果）就会经过那家服务商，这是它必须联网的唯一理由。
  • 没有云同步、没有多用户。数据只在这台手机上，换机靠备份文件，不靠账号。
  • 脚本目前是进程内沙箱。独立的隔离进程还在计划里——把引擎接口留好了，但这一版如实说没上。
  • 导出用系统分享。文件发到哪儿由你决定，App 不碰存储权限。
